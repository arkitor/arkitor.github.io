Integrated Building System

ArkiSIP™

A project-specific platform coordinating structural insulated steel panels with Arkitor mineral protection, interior, flooring and finishing systems.

Integrated for prefabricated construction

ArkiSIP is being developed for modular, laneway, secondary-suite, Indigenous, workforce and other prefabricated housing applications where lighter assemblies and faster enclosure can create practical advantages.

Prefab Integrated

Coordinates insulated panel construction with Arkitor interior, exterior, flooring and decorative layers.

Project Engineered

Assembly thickness, structural design, thermal performance, fastening and code compliance must be determined for each project.

In Development

ArkiSIP is a developing system platform, not a single pre-approved universal assembly.

ArkiSIP configurations are project specific. Engineering, local code review, envelope detailing and applicable test documentation are required before construction.
